Privacy policy

Application: Personal Workflow Assistant
Last updated: 27 October 2026

This is a private, single-user personal administration tool. Its account owner controls its configuration, connected accounts, selected records and authorised communications. These public pages contain information about the tool, not the owner's private records.

Google data and permissions

The application requests only the Gmail permissions needed for its email workflow:

  • gmail.readonly: read-only access used for bounded searches of relevant correspondence. The current workflow checks message identifiers, headers and short snippets to detect existing communications and avoid duplicates. Although this permission can permit broader reading, the application limits its own searches.
  • gmail.send: send owner-authorised messages and selected attachments from the connected account. This includes scheduled sending within the owner's configured instructions after automated checks and independent reviews.

The application also checks the connected account's identity to prevent use of the wrong account. It does not request permission to delete mail, change mailbox labels or administer the Google account.

How information is used and shared

Gmail information is used for the described communication checks and sending. Recipients receive the message and any selected attachments addressed to them. Google processes the Gmail API requests and stores sent mail under the connected account's normal settings.

When enabled, GitHub Actions runs the private workflow. Its configured storage uses an encrypted private-state bundle, which the workflow decrypts during execution. Cloud activation requires OAuth credentials, the encryption key and the AI service key to be held as GitHub Actions secrets rather than in public source files. Private state can include owner-selected professional records, workflow decisions and communication receipts. Encryption does not prevent access by an authorised running workflow.

For automated drafting and review, the application sends sanitised professional information chosen by the owner and public source information to OpenRouter and its selected model provider. Direct personal contact details are removed from model-visible professional text. This sanitisation is not a guarantee of complete anonymity. Gmail correspondence, including headers and snippets obtained through the Gmail API, is not sent to those AI services.

The application does not sell Google user data, use it for advertising, or use it to train or improve general-purpose AI models. It does not make Google correspondence available to other users. Google API data is used only for the disclosed workflow, subject to the Google API Services User Data Policy, including its Limited Use requirements.

Service providers have their own processing, security and retention practices. See Google's privacy policy, GitHub's privacy statement and OpenRouter's privacy policy. Model-provider terms and the owner's OpenRouter settings also apply to the sanitised professional information sent for AI processing. This application does not promise that every free model provider offers zero retention.

Retention, control and deletion

Private workflow state is retained until the owner removes it; the application currently has no automatic deletion period. Encrypted state updates, repository history, backups and workflow logs may retain earlier versions. The owner must remove applicable copies and use the providers' deletion controls when deleting the workflow. Email already sent remains subject to Gmail and recipients' own retention.

The owner can pause scheduled execution and revoke access through Google Account third-party connections. Revocation stops future authorised Google API access; it does not erase existing workflow records or messages already sent. To remove stored access, the owner can delete the application's OAuth tokens and service secrets and remove its private state and retained copies. Provider-held records follow the relevant provider's deletion process.

This public site

These static pages contain no forms, sign-in controls, analytics scripts or advertising. When hosted on GitHub Pages, GitHub may process visitor information such as IP addresses under its own privacy policy. This site does not collect private workflow records.

Questions and changes

For support or privacy questions, use the support contact shown on the application's Google consent screen. Material changes to Google data use require an updated disclosure and the owner's consent before the new use begins.
